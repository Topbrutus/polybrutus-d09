The source ZIP must come **only** from the frozen public Git tag and be
sha256-verified before uploading to Zenodo. Its companion
`results/certificate_d09.json` must be verified against regenerated output.

**Zenodo method:** direct REST API controlled draft; disable any simultaneous
GitHub-to-Zenodo automatic release harvesting to avoid duplicate DOI records.
**Cross-links:** DOI in README, CITATION.cff and release_manifest after public
verification. Retain the original scientific source tag unchanged. AI disclosure
is required in the record.

No private user documents or API keys are part of the publication.
